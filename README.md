# Jumping Battle

손끝 반응속도, 기억력, 집중력을 짧고 강하게 겨루는 **네온 터치 아케이드 게임**입니다.

## 게임 모드

- **번개전 · 30초** — 파란 타깃과 황금 보너스를 빠르게 터치하고 빨간 함정을 피합니다.
- **기억전 · 40초** — 화면에 나타난 빛의 순서를 기억해 그대로 입력합니다.
- **카오스 · 35초** — 5초마다 정답 규칙이 뒤집히는 상황에 즉시 적응합니다.

## 핵심 기능

- 반응속도 보너스, 콤보, 점수 배수, 피버 모드
- 일일 미션, XP, 레벨, 연속 플레이 기록
- 모드별 개인 최고 기록과 로컬·온라인 랭킹
- 모바일·태블릿·데스크톱 반응형 레이아웃
- 사운드, 진동, 일시정지, 자동 일시정지, 결과 공유
- 키보드 조작과 접근성 속성 지원
- Firebase 연결 실패 시에도 플레이 가능한 로컬 우선 구조

## 실행

별도의 빌드 과정이 없는 Vanilla HTML/CSS/JavaScript 프로젝트입니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 조작

- 터치 또는 마우스 클릭: 타일 선택
- `Space`: 시작 화면에서 게임 시작
- `P`: 일시정지·재개
- `Esc`: 플레이 중 일시정지

## 기술 구성

- HTML5 / CSS3 / Vanilla JavaScript
- Firebase Firestore 온라인 랭킹
- LocalStorage 로컬 프로필·기록
- Web Audio API 사운드
- Pointer Events 기반 터치·마우스 입력
